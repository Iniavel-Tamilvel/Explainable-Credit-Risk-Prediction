# Explainable Credit Risk Prediction

A supervised-learning project comparing Logistic Regression and Random Forest for hypothetical loan-default prediction.

**Workflow:** EDA → train/test split → model comparison → ROC-AUC/precision/recall/F1 → stratified cross-validation → feature importance.

**Responsible-use note:** the data is synthetic and must not be used for real credit decisions.

## Run
```bash
pip install -r requirements.txt
python notebooks/credit_risk_analysis.py
```
